### 🚀 Desenvolver firmware profissional exige mais do que apenas "fazer funcionar".

Muitos desenvolvedores ficam presos às limitações das bibliotecas de alto nível (HAL), enfrentando códigos inchados, comportamentos opacos em interrupções e um desperdício crítico de recursos de hardware.
Lidar com camadas de abstração genéricas muitas vezes significa herdar latências desnecessárias e dificuldades extremas em debugar problemas de tempo real. Para equipes de engenharia de alta performance, a diferença entre um código "que roda" e um código "otimizado para o metal" é o que define um especialista.

---

### 🛡️ A Solução: Domínio de Hardware via CMSIS

Este repositório é uma demonstração de **Engenharia de Software Embarcado de alto nível**. Aqui, abandonamos o HAL para abraçar a manipulação direta de registradores, focando no que realmente importa:

*   **Rigor Profissional:** Organização seguindo **GitFlow** e **Conventional Commits**, refletindo um fluxo de trabalho de padrão industrial.
*   **Controle Cirúrgico:** Drivers implementados sob medida para o STM32F072.
*   **Performance Extrema:** Redução drástica de overhead em rotinas críticas (ISR), essencial para aplicações de baixa latência.
*   **Transparência Total:** Código baseado puramente em CMSIS, facilitando a rastreabilidade e o debugging direto via mapa de registradores.
